1. EXECUTIVE SUMMARY & CORE VALUE PROPOSITION
================================================================================
SnapSched is an intelligent student academic companion and schedule manager.
Key capabilities:
- Instant AI Schedule Import: Take a photo of an enrolled COR/Study Slip and let
  Gemini Vision OCR automatically build the full weekly schedule in seconds.
- Vacant Period & Break Detection: Automatically detects and calculates gaps
  between classes to help students structure study or meal breaks.
- Integrated Study Focus Timer: Built-in Pomodoro timer tailored for vacant slots.
- Social Friend Compare: Find shared free hours across multiple friends' schedules.
- Multi-Category Support: Color-coded organization for School, Work, Gym, Study,
  and Personal activities.

================================================================================
2. MOBILE INFORMATION ARCHITECTURE & NAVIGATION (5-TAB BOTTOM BAR)
================================================================================
On mobile, navigation is structured around a persistent Bottom Tab Bar:

[ Tab 1: Timetable ] -> Daily/Weekly timetable grid & agenda, live class countdown
[ Tab 2: AI Scanner ] -> Camera/Gallery upload, scanning beam, OCR review table
[ Tab 3: Planner ]   -> Vacant periods breakdown, recommended tasks, Pomodoro timer
[ Tab 4: Compare ]   -> Social schedule compare, shared free slots calculator
[ Tab 5: Settings ]  -> Semester profiles, student info, categories, data backup

SCREEN 2: AI SCHEDULE SCANNER (ScannerScreen)
--------------------------------------------------------------------------------
Purpose: Instant schedule extraction from photos of Certificate of Registration (COR),
study load sheets, or portal screenshots using Gemini Vision AI.

Visual Wireframe:
+------------------------------------------------------------+
| [ < Back ]             AI Schedule Scanner                 |
+------------------------------------------------------------+
| [✨ Powered by Gemini Vision OCR]                          |
| Upload your registration slip, study load, or photo.       |
|                                                            |
| + - - - - - - - - - - - - - - - - - - - - - - - - - - - -+ |
| |                        [ CAMERA ]                      | |
| |               Drop or capture schedule photo           | |
| |              PNG, JPG, PDF, or Document Slip           | |
| |                                                        | |
| |     [ 📸 Open Camera ]        [ 🖼️ Photo Gallery ]      | |
| + - - - - - - - - - - - - - - - - - - - - - - - - - - - -+ |
|                                                            |
| --- OR Paste Plain Text / OCR Text ----------------------- |
| [ Enter raw text or schedule table...                    ] |
|                                                            |
|                   [ ✨ Scan Schedule ]                     |
+------------------------------------------------------------+

Scanning & Verification Flow:
1. Capture/Upload:
   - User snaps a photo or chooses an image from the gallery.
2. Animated Scanning State:
   - Futuristic neon glowing light beam scans across the document preview.
   - Progress bar with real-time percentage (e.g. "Extracting subjects... 85%").
3. OCR Review Table (BottomSheet or Sub-screen):
   - Displays all extracted subjects in an editable list.
   - Fields extracted: Subject Code, Description, Section, Units, Days (MWF/TTH),
     Start Time, End Time, Room, Instructor.
   - User checkboxes allow selecting/deselecting individual courses.
   - Two Import Modes:
     * "Replace Schedule": Clears existing classes and saves scanned set.
     * "Append Classes": Merges scanned classes with existing timetable.

4. CORE MODALS & BOTTOM SHEET SPECIFICATIONS
================================================================================

MODAL A: ADD / EDIT CLASS SHEET (ClassModal)
- Type: Draggable Interactive Bottom Sheet (50% to 90% snap points)
- Form Fields:
  1. Category selector (School, Work, Gym, Study, Personal + colors)
  2. Subject / Activity Code (e.g. "IT 311")
  3. Subject / Activity Name (e.g. "Advanced Web Systems")
  4. Section (e.g. "BSIT 3-A")
  5. Room / Location (e.g. "CL 304")
  6. Instructor Name (e.g. "Prof. R. Santos")
  7. Units count (e.g. 3.0)
  8. Day Selector: Pills [M] [T] [W] [TH] [F] [S]
  9. Time Wheel / Drum Pickers: Start Time (07:30) & End Time (09:00)
 10. Notes / Homework text area
 11. Action Buttons: [ Save Class ] and [ Delete Class ]

MODAL B: VACANT PERIOD DETAIL SHEET (VacantModal)
- Shows gap duration (e.g. "2 hours free").
- Displays previous class ending time and next class start time with room.
- Button to jump directly into the Focus Timer.

5. GESTURES, MICRO-INTERACTIONS & MOBILE UX GUIDELINES
================================================================================
1. Swipe Between Days:
   - Swiping left/right on the timetable canvas seamlessly transitions to adjacent days.
2. Haptic Feedback:
   - Light haptic tap on day change, category switch, or tab selection.
   - Success haptic buzz when AI scanning completes or class is saved.
   - Warning haptic when deleting a class.
3. Offline-First Architecture:
   - All schedules, categories, and settings are cached locally.
   - The app functions 100% offline (AI scanning requires network or local key).
4. System Theme Support:
   - Light Canvas: Soft gradient (#E0E7FF to #EDE9FE on #F4F6FC).
   - Dark Canvas: Deep slate glassmorphic theme (#0F172A).

6. COMPLETE DATA MODELS (TYPESCRIPT / DART SPECIFICATIONS)
================================================================================

```typescript
export type DayAbbreviation = 'M' | 'T' | 'W' | 'TH' | 'F' | 'S';

export interface CategoryItem {
  id: string;
  name: string;
  color: string;
  isDefault?: boolean;
}

export interface ClassItem {
  id: string;
  code: string;               // e.g. "IT 311"
  name: string;               // e.g. "Web Systems & Technologies 2"
  category: string;           // "School" | "Work" | "Gym" | "Study" | "Personal"
  section?: string;           // "BSIT 3-A"
  instructor?: string;        // "Prof. R. Santos"
  room: string;               // "CL 304"
  days: DayAbbreviation[];    // ["M", "W", "F"]
  startTime: string;          // "07:30" (24h format HH:mm)
  endTime: string;            // "09:00" (24h format HH:mm)
  color: string;              // HEX color code (e.g. "#4F46E5")
  units?: number;             // e.g. 3
  notes?: string;
  scheduleId?: string;
}

export interface VacantPeriod {
  id: string;
  day: DayAbbreviation;
  dayFull: string;
  startTime: string;          // "12:00"
  endTime: string;            // "15:00"
  durationMinutes: number;    // 180
  durationFormatted: string;  // "3 hrs"
  previousClassName: string;
  nextClassName: string;
  nextClassRoom: string;
  isToday: boolean;
}

export interface ScheduleSet {
  id: string;
  name: string;               // "1st Semester 2026-2027"
  semester: string;           // "1st Semester"
  academicYear: string;       // "2026-2027"
  studentName?: string;
  studentId?: string;
  course?: string;
  isDefault: boolean;
  createdAt: string;
  items: ClassItem[];
}
```

7. RECOMMENDED TECH STACK FOR MOBILE IMPLEMENTATION
================================================================================

- Camera & Photos: expo-camera and expo-image-picker
